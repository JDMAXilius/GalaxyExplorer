# UI refinement — user feedback

This records the user's accepted direction for the next discovery round, not implementation approval.

- Keep a short bottom dock: Explore, Guide, Room.
- Keep Settings separate in the corner.
- Keep primary exploration navigation on the side: Cosmic Web, Galaxies, Milky Way, Solar System. Exact grouping remains open.
- Hand tracking drives manipulation; remove explicit Resize and Return controls from the concepts.
- Explore palm-based menu access while retaining the compact dock; avoid duplicating all global controls on the palm.
- Offer Row and True Size solar-system layouts with clear selected state. True Size means relative physical proportions, not life-sized celestial bodies.
- Prefer the familiar information-card structure, with clean imagery integrated into the card, concise text, relevant facts, Listen and Compare.
- Explore a galaxy selector inspired by the planet-thumbnail strip and Places breadcrumb. Galaxy selection must remain distinct from layout selection.
- Continue iterative narrowing: hold accepted elements fixed and vary unresolved structure rather than proposing unrelated new styles.
- Current round has five visual proposals: wider side atlas with local layout choices; galaxy thumbnail shelf; palm-opened explorer; narrow context rail with lighter card; expandable side galaxy browser.

All images are conceptual. They do not verify gesture comfort, readability on Quest, scientific image placement, or exact facts. Those need a subsequent specification and runtime/device validation. No Figma edits or application changes were made.
